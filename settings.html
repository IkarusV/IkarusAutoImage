Character Prompt
5 slots per character card. Only the active slot is injected via {CharacterPersonalised-prompt} macro. Dot = slot has content.
Char Prefix
Prepended to every image prompt for this character (e.g. LoRAs, quality tags). Applies to this extension's pic prompts, and to all /sd prompts when "Filter native /sd" is enabled.
Replacements
Find trigger words and swap them in-place. Supports children (more specific variants that auto-win over parent). Click 👶 on a card to add a child.
Add Replacement
The first group contains replacement targets. Additional groups are AND conditions supporting OR, AND, XOR, and NOR.
First match gets the full selected replacement text. Every remaining match gets this text instead.
Filters
Trigger-based actions: remove words, append tags, or replace text when trigger keywords are detected.
Add Filter
All groups are combined with AND. Within each group choose OR (any), AND (all), XOR (exactly one), or NOR (none).
